# 手動テストデータ投入手順

## 1. 目的

`ManualTestDataSeeder` は、`品川高等学院_LMS_テスト仕様書.xlsx` に沿ってLMSを画面操作で確認するための専用テストデータを投入する。

投入できる環境は `local` または `testing` のみとする。本番環境では実行できない。

授業名、時間割、クラス構成、カリキュラム、年間行事、提携校は品川高等学院公式HPの公開情報を正とする。公式HPに公開されていない生徒名、教員名、Google Workspaceの実IDはQA専用データとして作成する。

## 2. 公式情報の参照元

- 学校公式HP: https://shinagawahs.jp/
- 英語カリキュラム: https://shinagawahs.jp/course/english-curriculum/
- AIリテラシー教育: https://shinagawahs.jp/course/ai-literacy/
- キャリア教育: https://shinagawahs.jp/course/financial-education/
- 年間行事: https://shinagawahs.jp/school-life/annual-events/
- 個別相談: https://shinagawahs.jp/consultation/

## 3. 投入方法

既存のローカルDBへテストデータだけ追加・更新する場合は次を実行する。

```powershell
php artisan db:seed --class=ManualTestDataSeeder
```

テストDBを完全に作り直してから投入する場合は、既存データが全削除されることを確認したうえで次を実行する。

```powershell
php artisan app:setup-local
php artisan db:seed --class=ManualTestDataSeeder
```

同じSeederは複数回実行できる。QA用マスタ、ユーザー、授業、評価、お知らせなどは同じ識別条件で更新される。

## 4. 共通ログインパスワード

全QAアカウントの共通パスワードは次のとおり。

```text
TestPass2026!
```

本データはローカル・テスト環境専用であり、本番アカウントには使用しない。

## 8. 時間割・出欠

午前の部は次の3時限を使用する。

- 1限: 10:00〜10:50
- 2限: 11:00〜11:50
- 昼休憩: 11:50〜12:20
- 3限: 12:20〜13:10

午後の部は次の3時限を使用する。

- 1限: 13:30〜14:20
- 2限: 14:30〜15:20
- 休憩: 15:20〜15:50
- 3限: 15:50〜16:40

1年A・2年A・3年Aには午前時間、1年B・2年B・3年Bには午後時間を設定する。午後を4〜6時限として扱わない。

前年度切替確認用として、1年Aクラスには同じ公式掲載時間割を前年度データとしても用意する。これは画面の年度切替確認用であり、過年度実績を表すものではない。

出欠確認用データは公式時間割に存在する授業枠だけを使用し、土日や架空の6限は作成しない。平日にSeederを実行した場合だけ、その日の1年Aクラス1限を当日表示確認へ使用する。

- 完了授業、休講授業、未入力出欠を作成する。
- 出席、欠席、遅刻、早退を混在させる。
- 管理者修正済み出欠を1件以上作成する。

## 9. 評価

年間評価として次の状態を混在させる。

- 確定済み
- 下書き
- 未入力
- 5段階評価あり
- 総合点・提出物・出欠・授業態度の異なる値

これにより教員入力、管理者確認・訂正、生徒参照の確認に使用できる。

## 10. 面談

公式HPの年間行事・カリキュラムに合わせ、次の名称を中心に登録する。

- 学習計画面談
- 前期振り返り
- 進路ガイダンス
- 探究活動面談
- 進路面談
- 個別面談

## 11. お知らせ

次の状態と公開範囲を作成する。

- 全員向け
- 生徒ロール向け
- 教員ロール向け
- 1年生向け
- 2年生向け
- 1年Aクラス向け
- 1年Bクラス向け
- 下書き
- 未来公開
- 公開終了
- 重要表示

内容には公式HPの年間行事である校外学習・体験活動、進路ガイダンス、探究発表・作品制作、キャリア学習などを使用する。

## 12. 外部リンク

公開範囲の確認用として次を用意する。

- 全体: 年間行事公式HP
- 生徒ロール: 個別相談公式HP
- 全体: Google Drive
- 生徒ロール: Google Chat
- 個人生徒: Google Meet
- 1年Aクラス: Google Drive
- 1年Aクラス「基礎英語」: Google Classroom
- 無効リンク

Google Drive、Calendar、ChatのAPI内データはSeederでは作成しない。各ユーザーが接続したGoogle Workspaceアカウントの実データを使用して確認する。

## 13. 操作ログ

操作ログは60件作成する。ページング、検索、日付絞り込み、CSV出力を確認できる件数とする。

先頭ログにはCSV数式インジェクション対策確認用として次の値を含める。

- `=SUM(A1:A2)`
- `+1+1`
- `-1+1`
- `@SUM(A1:A2)`

## 14. テスト仕様書との実装差異

現行LMSのお知らせ公開対象は次の4種類である。

- 全員
- ロール
- 学年
- クラス

テスト仕様書に記載された「授業」「個人」単位のお知らせ公開対象は現行実装には存在しないため、Seederでは作成しない。

外部リンクは現行LMSで「全体・ロール・クラス・授業・生徒」の公開範囲を持つため、すべての範囲をSeederで作成する。

## 15. テスト終了後

QAデータを完全に消して通常の初期状態へ戻す場合は、ローカルDB全削除を許容できることを確認して次を実行する。

```powershell
php artisan app:setup-local
```

`app:setup-local` はDB全体を再作成するため、必要なデータが残っていないことを確認してから実行する。
